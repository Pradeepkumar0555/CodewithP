# ❤️ Apology Letter & 1000 Sorries (Mera Pyara Sa Bacha)

An ultra-sweet, romantic, and interactive apology website dedicated to **Mera Pyara Sa Bacha**.

---

## 🌟 Features Included

1. **💌 Heartfelt Apology & Confession**:
   - Genuine apology acknowledging yesterday's mistake of getting angry without any reason.
   - Dedicated to: *"Mera Pyara Sa Bacha"*.

2. **🙏 The 1000 Times Sorry Machine**:
   - Dynamic counter counting from 0 to 1000.
   - Rapid shower button: Instantly sends 1000 Sorries with animations.
   - Modal book: Complete list showing pure *"Sorry"* 1000 times (#1 to #1000).

3. **🌹 Romantic Apology Shayari**:
   - 4 heart-touching shayaris written especially for Mera Pyara Sa Bacha.

4. **👑 5 Reasons Why You Are An Angel**:
   - Heartfelt, sincere confession points on why you are an angel and why I was completely wrong.

5. **🎟️ Interactive Peace Treaty Coupons**:
   - Redeemable cards: Bear Hug, Favorite Ice Cream Treat, 24-Hour Yes-Man, Princess Treatment.

6. **🏃 Playful "Maan Jao Na" Arena**:
   - Interactive **"Haan, Maan Gayi! 🥰"** button with confetti fireworks.
   - Playful **"Nahi, Abhi Bhi Gussa Hu!"** runaway button that moves away on touch/hover with teasing messages!

7. **🎵 Ambient Melody Synthesizer**:
   - Uses Web Audio API with zero external audio files needed.

8. **✨ Visuals & Aesthetics**:
   - Romantic rose-gold & pastel pink theme.
   - Floating heart particles on HTML5 canvas.
   - 100% mobile responsive.

---

## 🚀 How to View Locally

Simply open `index.html` in any web browser.
